# SDLC 看板改版记录（0.1.1，2026-10-17）

## 原因与处理

旧版把任务列表、完整裁决、迁移日志同时挤在一个宽度受限的区域里。
列表的 flex 固有最小宽度又受长标题影响，导致左侧越来越宽、详情被挤窄。
三个原型变体各维护一套布局，调整字号和颜色不能解决这些结构问题。

现在统一为任务列表与详情两栏。CSS Grid 给两栏明确的宽度边界，内容可收缩，
列表和详情独立滚动。概览先显示当前阶段、验证结论、交付物、最近进展，
完整历史移到单独页签，长记录可展开，历史条数不再截到最后 8 条。

状态、工作区、关键词三个筛选都使用实际任务数据。窄屏切成列表 / 详情两步，
阶段条在自己的区域内横向滚动。颜色沿用宿主主题，深色模式提高强调色亮度。
交付物用原生 dialog，支持 Escape、焦点圈定和返回原触发按钮。

同时修正任务身份：任务编号只在一个工作区内唯一，选中态、React key、详情与
交付物读取统一使用 `(repoRoot, id)`，防止两个工作区同名任务串到一起。

命令：`npm run verify -w @ai-native-sdlc/dsh-sdlc`。
（本记录写于 0.1.1，合并前的包名是 `@ai-native-sdlc/dsh-sdlc-ui`；合并后组件在
`packages/sdlc/src/ui/`。——**当前照做请用上面这条命令。**）

|---|---|---|
| board.test.mjs | 24 / 24 | 宿主任务扫描与工作区聚合 |
| client.test.mjs | 8 / 8 | 组件交互、同名任务身份、筛选、完整历史、空态 |
| smoke.mjs | 40 / 40 | bundle 求值、槽注册、端点契约与来源标识 |
| playground 隔离副本 make check | 21 / 21 | 真实 LocalFileSystem 的建任务、制品、迁移与回退 |

组件交互桩不执行 effects，不拿它宣称 DOM、网络、焦点或布局已验证。
同一份 client.test.mjs 打在改版前 client.js 上为 1 通过 / 7 失败，其中两条是
旧版确有的同名任务选中 / 制品来源问题，其余主要是新增交互要求，不能全称回归。
旧冒烟为 42 条；删除原型变体后不再重复测两套界面，现为 40 条。

真实 DSH Web 使用独立 DSH_HOME，读取实际登记的工作区；没有发起模型调用。
实测 3 个工作区 / 13 个任务，筛选 playground 后 2 个任务，完成 / 进行中各 1 个。
搜索、无匹配后清除、文件正文、全部迁移记录、记录展开均实际操作过。
弹窗 Escape 关闭后焦点回到 intent.md 按钮。浏览器采集到的 warning / error 为空。

响应式实测请求视口 1440×1000 与 390×844；宿主有缩放，DOM 实际视口分别为
1600×1111 与 433×937。小屏看板、详情没有整页横向溢出，列表→详情→返回可用。
浅色、深色都与概念图比对，使用真实任务内容，保留 DSH 自身侧栏。
