# RSI 任务证据与插件改进

## 验收标准
R1. 独立 preset 的验证会话可以被采集；不相关的标准会话不被记录；会话 ID/事件序号去重，支持日志查询补漏，缺失、截断、查询失败不伪装完整。
R2. 任务创建及后续操作关联作者会话，验证 run 关联同一任务；持久化任务进度、会话证据与版本信息。查询和重启后能恢复已登记的关系，不按时间或最近任务猜归属。
R3. 生命周期完成与证据完整分开报告。DEMO-22149 同形的空 trace、空配置和失败快照必须被分析识别；来源不足时禁止可比结论。
R4. 多仓库工作区可以逐仓库保存 HEAD、dirty diff、新文件及指纹；范围与缺失明确记录。记录变化不会改变代码指纹；代码变化和取样中漂移仍会被发现。
R5. 按任务生成有证据引用的复盘材料，支持将结构化改进假设导出为正常 SDLC 任务，并关联基线/候选版本、可复跑对照证据与采用后反馈。诊断不把五次 reject 自动解释为验证器故障。
R6. 用真实 Cordis 作用域、工具调度和文件系统做旧版/新版对照；新增反例覆盖记录故障、不相关会话、并发、恢复、代码变化。build/test/smoke、compat、preset-sync、基准和隔离 tarball 验证通过。

## 实现边界
本轮先交付完整证据、可追溯改进任务和确定性插件版本对照。模型行为实验仍须隔离参考答案、固定环境并重复运行；现有共享文件系统实验继续只作探索。后续真实任务效果由版本关联反馈持续记录，不在一次实现中声称普遍提升。
