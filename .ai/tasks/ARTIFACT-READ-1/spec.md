# 验收标准

1. 已登记的 `verifications/<run-id>.json` 能从阶段入口打开，正文与所选文件一致；登记外、路径穿越和越界软链仍不可读，缺失文件明确返回 404。
2. 验证报告默认展示结论、逐条验收结果、发现、修改建议、问题复验及未验证事项。稳定 ID 对应完整标准，结果重排不串项；无完整裁决不能显示通过。
3. 评审报告兼容不同字段结构，保留评审过程、风险、未采纳和未知字段。没有评审结论时明确缺失，不借用验证的 approve。
4. 默认不展示 JSON 代码块；可展开完整原文。超过旧 200,000 字符的有效文件不能被截坏；超过 16 MiB 明确报错，损坏 JSON 说明原因并保留原文。桌面与窄屏可阅读、关闭并返回原阶段，Markdown 行为不变。

本次不改任务状态机、验证器裁决或原任务文件。运行中的日常 DSH 是否加载新版单独核实，不以安装成功代替进程版本证明。
