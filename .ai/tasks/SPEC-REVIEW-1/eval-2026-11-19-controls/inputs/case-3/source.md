# 局部接口的原始任务说明

本次只承诺以下有限输入集合的返回值。接口名是名称，不附带集合外的通用算法承诺；未列出的输入（包括同类型其他取值）不在本次交付范围。这是为了独立检验“明确局部范围”的受控任务，不代表真实业务需求。

下文所有引号内文本按 Python 字符串字面量解释；\t 表示一个 U+0009 制表符。所有字符串返回值是精确完整值，不包含额外字符。

接口位于 app.gettext_helpers：
- add(2, 3) == 5；add(-2, 3) == 1。
- render("x") 返回按 U+003C、U+0078、U+003E 顺序且各一次拼接的字符串；render("") 返回按 U+003C、U+003E 顺序且各一次拼接的字符串。
- extract("a b") == ["a", "b"]；extract("  a\tb  ") == ["a", "b"]；extract("") == []。
- normalize("  x  ") == "x"；normalize("  ") == ""。

验收须逐项穷举以上 9 组输入输出。完整 gettext 构建、add_uids、extract_messages、CLI、额外环境及其他独立符号均不在范围内。不要求实现特定算法，也不要求在范围外表现如何。
